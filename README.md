# AWS AI/ML User Group Kenya Website

## Installation steps
1. Clone the repo: ``` git clone [https://github.com/AWS-AIML-Kenya/aws-ug-frontend.git] ```

2. cd into the directory: ``` cd aws-ug-frontend ```

3. Install packages: ``` pnpm install ```

4. Run the application: ```pnpm run dev```# aws-ai-ml
